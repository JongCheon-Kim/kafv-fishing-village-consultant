# KAFV 제3차시 수산물 위생·안전관리의 이해 v0.7.20 (부캉이 통합판)

한국AI어촌가치연구소(KAFV) · 우리어촌컨설턴트


## 변경 사항
- 제4차시 v0.4.9의 부캉이 UI 및 강의록 3단 구성 적용
- 34페이지별 주요 용어·그림 해설, 76개 용어·54개 예상질문/답변(34개 페이지별 질문 + 기존 퀴즈 20개)
- 기존 토의 질문은 접이식 영역에 보존
- 외부 AI API 호출 없이 내장 지식 DB로 응답하며, 실제 안전성 판정·최신 법령 확인을 대체하지 않음
- 기존 교육 이미지, 나레이션, 실습 엔진 및 전체화면 클릭 복귀 스크립트 보존
